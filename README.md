# Региональные панели СберИндекса

Четыре исследования на открытых выгрузках СберИндекса, продолжающие [«Шок по расписанию»](https://github.com/rav11l/sberindex-shocks) там, где у той работы не хватало данных.

| Исследование | Вопрос | Данные |
|---|---|---|
| [Ковид, эхо и панель](docs/covid.md) | что детектор сдвигов видит, а чего не видит на настоящем шоке | внутренний туризм, 83 региона, 01.2019–04.2022 |
| [Длинная панель](docs/deals.md) | держится ли панельный приём, когда точек прогноза достаточно для тестов | цены сделок с жильём, 85 регионов × 2 сегмента, 01.2017–09.2026 |
| [Разрыв «объявление минус сделка»](docs/gap.md) | что он измеряет и предсказывает ли цены | объявления Домклик против сделок, 83 региона, 01.2022–09.2026 |
| [Новизна жилья](docs/novelty.md) | из чего состоит разрыв первички и вторички и сколько в росте цен состава | цены по возрасту жилья, 75 регионов, 10.2022–09.2026 |

Первая работа закрывает дыру в проверке детекторов: паводки 2024 года были сравнимы с шумом, а ковид дал обвал на 68 процентных пунктов с известной датой. Вторая снимает оговорку о мощности: вместо шести целевых месяцев — несколько десятков. Третья и четвёртая связаны: третья находит схождение цен объявлений и цен сделок, четвёртая показывает, что оно держится на составе сделок, и снимает её главный вывод. Правка внесена в текст третьей работы, а не задним числом в её числа.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt && pip install -e . --no-deps
powershell -File scripts\download.ps1                  # выгрузки + сверка sha256
python -m siregions.cli covid    --config configs/covid.yaml
python -m siregions.cli forecast --config configs/deals.yaml
python -m siregions.cli gap      --config configs/gap.yaml
python -m siregions.cli novelty  --config configs/novelty.yaml
```

Сырые выгрузки в репозиторий не кладутся: их скачивает скрипт, а версия фиксируется контрольной суммой в `data/raw/manifest.json`. Все параметры — в YAML, любой ключ переопределяется через `--set`.

## Устройство

| Файл | Что внутри |
|---|---|
| `src/siregions/data.py` | чтение выгрузок, сверка хешей, построение панелей |
| `src/siregions/covid.py` | разложение на общую и идиосинкразическую части, признак эха, прогон детекторов |
| `src/siregions/forecast.py` | скользящий бэктест на длинной панели |
| `src/siregions/gap.py` | разрыв объявлений и сделок: описание, связь со ставкой, опережение, прогнозная ценность |
| `src/siregions/novelty.py` | премия за возраст жилья, восстановление сдвига состава, разложение роста цен |
| `src/siregions/panelreg.py` | within-регрессия с поглощением эффектов, кластерные ошибки, Ньюи–Уэст |
| `src/siregions/changepoint/` | детекторы: z-score, панельный, CUSUM, BOCPD, PELT, BinSeg |
| `src/siregions/models/` | наивные модели, ETS на отклонении, Prophet (в том числе на отклонении), модели-основы |
| `src/siregions/backtest.py` | метрики, тест Диболда–Мариано с поправкой на перекрытие, блочный бутстрап |
| `tests/` | проверки ключевых утверждений, включая отсутствие заглядывания вперёд |
