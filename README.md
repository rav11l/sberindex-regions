# Региональные панели СберИндекса

Пять исследований на открытых выгрузках СберИндекса, объединённых одним приёмом: ряд рассматривается не сам по себе, а как отклонение от общего фактора панели. Приём простой, но он решает и задачу прогноза, и задачу обнаружения сдвигов, и вопрос «кто раньше» — а заодно отсекает часть эффектов, которые при обычном взгляде кажутся настоящими.

Депозит: [10.5281/zenodo.23318082](https://doi.org/10.5281/zenodo.23318082) — DOI всех версий, всегда ведёт на последнюю. Страница серии: [digitaleconomylab.ru/sberindex-regions](https://digitaleconomylab.ru/sberindex-regions).

Работы продолжают [«Шок по расписанию»](https://github.com/rav11l/sberindex-shocks) там, где у той не хватало данных: 24 месяца муниципальной панели не давали мощности для формальных тестов, а искусственные ступеньки не заменяли настоящий шок.

| Исследование | Главный результат | Данные |
|---|---|---|
| [Ковид, эхо и панель](docs/covid.md) | панельный детектор не видит общий шок — и по той же причине не ловит эхо базы: 0,08 тревог против 0,62 у детекторов на собственной истории | внутренний туризм, 83 региона, 01.2019–04.2022 |
| [Длинная панель](docs/deals.md) | контрольная модель без обученных параметров обыгрывает Prophet на 32 %, p < 0,0001; надстройка даёт ещё 357 руб. | цены сделок с жильём, 85 регионов × 2 сегмента, 01.2017–09.2026 |
| [Разрыв «объявление минус сделка»](docs/gap.md) | предсказательная сила разрыва — это возврат к среднему шумной цены сделки, а не информация в запросе продавца | объявления Домклик против сделок, 83 региона, 01.2022–09.2026 |
| [Новизна жилья](docs/novelty.md) | разрыв первички и вторички на 19 из 24 пунктов состоит из возраста жилья; состав сделок снимает главный вывод предыдущей работы | цены по возрасту жилья, 75 регионов, 10.2022–09.2026 |
| [Кто первым реагирует на ставку](docs/rate.md) | на повышение ставки группа 15–24 отвечает в ту же неделю (−1,3 % на п. п.), у 25–34 и 35–64 реакции нет | недельные траты по возрастам, Россия, 01.2021–10.2026 |

Третья и четвёртая работы связаны: третья находит схождение цен объявлений и цен сделок, четвёртая показывает, что оно держится на составе сделок, и снимает её главный вывод. Правка внесена в текст третьей работы, а не задним числом в её числа.

## Что здесь считается проверкой

В каждой работе результат проходит через набор проверок, и часть выводов их не переживает — это записано там же, где сам результат:

- плацебо: выдуманные даты событий, сдвинутые окна, объяснение прошлого вместо будущего;
- перестановочные тесты вместо доверия к p-значениям при перекрывающихся окнах;
- исключение по одному событию и по годам;
- вневыборочная проверка там, где утверждается предсказание;
- сверка чисел в текстах с результатами прогона — отдельным тестом (`tests/test_report_numbers.py`).

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt && pip install -e . --no-deps
powershell -File scripts\download.ps1                  # выгрузки + сверка sha256
python -m siregions.cli covid    --config configs/covid.yaml
python -m siregions.cli forecast --config configs/deals.yaml
python -m siregions.cli gap      --config configs/gap.yaml
python -m siregions.cli novelty  --config configs/novelty.yaml
python -m siregions.cli rate     --config configs/rate.yaml
```

Сырые выгрузки в репозиторий не кладутся: их скачивает скрипт, а версия фиксируется контрольной суммой в `data/raw/manifest.json`. Все параметры — в YAML, любой ключ переопределяется через `--set`.

## Устройство

| Файл | Что внутри |
|---|---|
| `src/siregions/data.py` | чтение выгрузок, сверка хешей, построение панелей |
| `src/siregions/covid.py` | разложение на общую и идиосинкразическую части, признак эха, прогон детекторов |
| `src/siregions/forecast.py` | скользящий бэктест на длинной панели |
| `src/siregions/gap.py` | разрыв объявлений и сделок: описание, связь со ставкой, опережение, прогнозная ценность |
| `src/siregions/novelty.py` | премия за возраст жилья, восстановление сдвига состава, разложение роста цен |
| `src/siregions/rate.py` | локальные проекции вокруг решений ЦБ, перестановочный тест, плацебо-сдвиги |
| `src/siregions/panelreg.py` | within-регрессия с поглощением эффектов, кластерные ошибки, Ньюи–Уэст |
| `src/siregions/changepoint/` | детекторы: z-score, панельный, CUSUM, BOCPD, PELT, BinSeg |
| `src/siregions/models/` | наивные модели, ETS на отклонении, Prophet (в том числе на отклонении), модели-основы |
| `src/siregions/backtest.py` | метрики, тест Диболда–Мариано с поправкой на перекрытие, блочный бутстрап |
| `tests/` | проверки ключевых утверждений, включая отсутствие заглядывания вперёд и сверку чисел отчётов |
